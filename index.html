Columns come from tags whose names start with the color pair, like “UB Dilemma – Payoff”. Add or rename tags on the Tags screen and they show up here. The sections below the columns list cards in these two colors, plus colorless cards.

Tags

Renaming a tag keeps it on every card it’s already on. Deleting a tag removes it from every card. You can also create tags while reviewing by typing a new name in the tag finder.
